# Fast exit: the game closes at once without loading the PC (Patapon 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Closing the window (X, Alt+F4, Ctrl+C) makes the window disappear at once, the process
exit within about 1 s with exit code 0, no saved data lost and no CPU burned while it closes.

**Architecture:** Today shutdown tears GE/GL down while the game keeps running, then joins each
guest thread with a 2 s timeout, one after another; no guest thread ever ends, so every join
times out. The fix stops the guest first: closing the guest CPU token (`psp_cpu`) parks every
thread the next time it would run guest code. The host then lets in-flight file writes finish
(a new write counter), tears down audio/GE/SDL and leaves with `std::_Exit(0)`. It never joins
guest threads, because the OS ends parked threads at process exit.

**Tech Stack:** C++17 runtime (`runtime/`), SDL2, CMake/Ninja (llvm-mingw clang), ctest unit
tests, Python tools in `DECO/build/tools/` (outside the repo).

**Spec:** this plan's "Problem" and "Evidence (before)" sections. There is no separate spec. The
user's words, 2026-10-16: "ver por qué tarda muchísimo en cerrarse el juego, al grado de que
mientras lo hace, alenta la PC".

## Review Focus

1. **Closing while a save is being written** (the user saves, then closes at once). The save on
   disk must be the old or the new one, never truncated. Covered by the write counter (Task 3)
   and the order in Task 4. Check `write_file_atomic` still runs to its rename.
2. **A guest thread that spins without HLE calls or contended loop back-edges.** It never reaches
   `psp_cpu_acquire`, so it never parks. Shutdown must still finish: `psp_cpu_wait_released`
   has a 1 s limit, then `_Exit` ends it.
3. **`PSPRECOMP_NO_CPU_LOCK=1`.** Threads must still park at their next acquire (the closed
   check comes before `enabled()`). Task 2 has its own ctest run with that variable.
4. **The closing (main) thread reaching guest code after close**, for example a GE finish
   callback during teardown. It must not park, or the process hangs forever. It exits at once
   instead (Task 2 `--closer` test). Task 4 also removes the post-close render-queue drain.
5. **Scripts and tools.** `p3drive.kill()` (TerminateProcess) must keep working. Patapon 1
   scripts read `frame.tga`, which `ge_draw_shutdown` writes, so that call stays in the
   sequence. Ctrl+C / SIGTERM (`signal_handler`) must take the same fast path. Check by hand:
   Ctrl+C in a console run exits fast.

Causes, read from the code:

- `runtime/src/psp_scheduler.cpp` `psp_scheduler_shutdown()`, lines 291-343: a sequential join
  with a 2 s timeout per guest thread. Guest threads never return, so 7 threads × 2 s = 14 s.
  Each try starts a `joiner` thread that is detached on timeout. That joiner captures
  `joined` (a stack local) and `t` by reference, which is undefined behaviour after the loop
  moves on: the likely source of the exit crash.
- `runtime/src/main.cpp` lines 522-532: `ge_draw_shutdown`, `ge_texture_shutdown` and
  `ge_shutdown` run **before** `psp_runtime_shutdown()` (the joins), so the still-running game
  uses a torn-down GE.
- `runtime/src/psp_event_loop.cpp` `psp_event_loop` / `psp_runtime_shutdown`: the window is
  only destroyed at the very end, so it stays frozen ("not responding") for the whole time.

Not explained yet: the PC "slowing down". At 12-30 % of one core on a 12-thread CPU, the
measured close is not heavy. Task 1 measures the whole machine (CPU, disk, GPU) and a mission
close before any code changes. If Task 1 finds another heavy cost (for example WER, a GPU
driver stall or a disk flush), record it in Evidence and fix it inside Task 4's sequence, or

    `[CPU] the closing thread asked for the CPU after close: exiting now`, flushes and calls
    `std::_Exit(0)`.

`runtime/tests/test_cpu_close.cpp`:

```cpp
// psp_cpu: closing the guest CPU at shutdown parks every thread that would run guest code again.
#include "psp_cpu.h"

#include <atomic>
#include <chrono>
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <thread>

static int failures = 0;
#define CHECK(cond, msg) \
    do { if (!(cond)) { std::printf("FAIL: %s\n", msg); failures++; } } while (0)

static bool wait_until(const std::atomic<int>& v, int want, int ms) {
    for (int i = 0; i < ms; i++) {
        if (v.load() >= want) return true;
        std::this_thread::sleep_for(std::chrono::milliseconds(1));
    }
    return v.load() >= want;
}
static bool wait_parked(int want, int ms) {
    for (int i = 0; i < ms; i++) {
        if (psp_cpu_parked() >= want) return true;
        std::this_thread::sleep_for(std::chrono::milliseconds(1));
    }
    return psp_cpu_parked() >= want;
}

static int run_closer() {
    // The closing thread must never park: asking for the CPU after close exits the process.
    psp_cpu_close();
    psp_cpu_acquire();
    std::printf("FAIL: closer came back from acquire\n");
    return 1;
}

int main(int argc, char** argv) {
    if (argc > 1 && std::strcmp(argv[1], "--closer") == 0) return run_closer();
    const bool nolock = argc > 1 && std::strcmp(argv[1], "--nolock") == 0;

    if (!nolock) {  // before close: normal hand-over
        std::atomic<int> got{0};
        std::thread a([&] { psp_cpu_acquire(); got = 1; psp_cpu_release(); });
        a.join();
        CHECK(got.load() == 1, "acquire works before close");
        CHECK(psp_cpu_wait_released(std::chrono::milliseconds(100)), "free after release");
    }

    // With the lock on: a holder running guest code and a waiter coming back from an HLE call.
    // With PSPRECOMP_NO_CPU_LOCK=1 nobody holds or waits (acquire returns at once before close),
    // so only the late thread below is checked.
    std::atomic<int> holder_has{0}, holder_go{0}, ran_after{0}, waiter_started{0};
    std::thread holder, waiter;
    if (!nolock) {
        holder = std::thread([&] {
            psp_cpu_acquire();
            holder_has = 1;
            while (!holder_go.load()) std::this_thread::sleep_for(std::chrono::milliseconds(1));
            psp_cpu_yield_if_contended();  // loop back-edge after close: parks
            ran_after = 1;
        });
        CHECK(wait_until(holder_has, 1, 1000), "holder took the CPU");
        waiter = std::thread([&] {
            waiter_started = 1;
            psp_cpu_acquire(/*front=*/true);  // blocked behind the holder
            ran_after = 1;
        });
        CHECK(wait_until(waiter_started, 1, 1000), "waiter started");
        std::this_thread::sleep_for(std::chrono::milliseconds(20));
    }

    psp_cpu_close();
    psp_cpu_close();  // idempotent
    holder_go = 1;
    const int expect = nolock ? 0 : 2;
    CHECK(wait_parked(expect, 2000), "holder and waiter parked");
    CHECK(psp_cpu_wait_released(std::chrono::milliseconds(500)), "nobody holds the CPU after parking");
    CHECK(ran_after.load() == 0, "no thread ran guest code after close");

    std::thread late([&] { psp_cpu_acquire(); ran_after = 1; });  // asks after close
    CHECK(wait_parked(expect + 1, 2000), "late thread parked");
    CHECK(ran_after.load() == 0, "late thread did not run");

    if (holder.joinable()) holder.detach();
    if (waiter.joinable()) waiter.detach();
    late.detach();
    if (failures == 0) std::printf("cpu_close%s: all tests passed\n", nolock ? " (no lock)" : "");
    std::fflush(nullptr);
    std::_Exit(failures == 0 ? 0 : 1);  // parked threads never return; do not run destructors
}
```

```cpp
/// Shutdown: close the CPU for good. Every later psp_cpu_acquire, and a holder's
/// psp_cpu_yield_if_contended, parks its host thread forever (no guest code runs again; the OS
/// ends parked threads at process exit). The calling thread is the closer: it never parks. If
/// it asks for the CPU after close it exits the process at once (it is closing anyway).
/// Idempotent.
void psp_cpu_close();

/// After psp_cpu_close: wait until no thread holds the CPU (the last holder reached an HLE
/// call or a contended back-edge and parked). False when `limit` passes first, e.g. a guest
/// loop that never calls the HLE.
bool psp_cpu_wait_released(std::chrono::milliseconds limit);

/// Threads parked by psp_cpu_close so far (diagnostics, tests).
int psp_cpu_parked();
```

```cpp
// psp_host_io.h — host file writes in flight (savedata, memory-stick files, data install,
// ad hoc config). Shutdown waits for them before it ends the process: a save written halfway
// is worse than a slower exit.
#pragma once

#include <chrono>

void psp_host_write_begin();
void psp_host_write_end();
int psp_host_writes_in_flight();
bool psp_host_writes_wait_idle(std::chrono::milliseconds limit);

struct PspHostWriteScope {
    PspHostWriteScope() { psp_host_write_begin(); }
    ~PspHostWriteScope() { psp_host_write_end(); }
    PspHostWriteScope(const PspHostWriteScope&) = delete;
    PspHostWriteScope& operator=(const PspHostWriteScope&) = delete;
};
```

`runtime/src/psp_host_io.cpp`:

```cpp
#include "psp_host_io.h"

#include <condition_variable>
#include <mutex>

namespace {
std::mutex g_m;
std::condition_variable g_cv;
int g_in_flight = 0;
}  // namespace

void psp_host_write_begin() {
    std::lock_guard<std::mutex> lock(g_m);
    g_in_flight++;
}

void psp_host_write_end() {
    {
        std::lock_guard<std::mutex> lock(g_m);
        g_in_flight--;
    }
    g_cv.notify_all();
}

int psp_host_writes_in_flight() {
    std::lock_guard<std::mutex> lock(g_m);
    return g_in_flight;
}

bool psp_host_writes_wait_idle(std::chrono::milliseconds limit) {
    std::unique_lock<std::mutex> lock(g_m);
    return g_cv.wait_for(lock, limit, [] { return g_in_flight == 0; });
}
```

```cpp
// psp_scheduler_wake_all — shutdown: set the exit flag and wake every scheduler wait. Guest
// threads are never joined: a PSP game does not end its threads, and after psp_cpu_close
```

```cpp
    // HLE return or loop back-edge), host file writes finish, then the host tears down and the
    // process ends with _Exit: guest threads are never joined (they never return), and static
    // destructors must not run under parked threads.
    const auto t_quit = std::chrono::steady_clock::now();
    auto stage = [&](const char* what) {
        const long long ms = std::chrono::duration_cast<std::chrono::milliseconds>(
            std::chrono::steady_clock::now() - t_quit).count();
        std::fprintf(stderr, "[RT] shutdown +%lldms %s\n", ms, what);
    };
    stage("quit requested");
    psp_debug_socket_stop();
    psp_cpu_close();
    psp_scheduler_wake_all();
    if (!psp_cpu_wait_released(std::chrono::seconds(1)))
        stage("a guest thread still holds the CPU (loop without HLE calls); exiting anyway");
    {
        char buf[64];
        std::snprintf(buf, sizeof buf, "guest stopped (%d threads parked)", psp_cpu_parked());
        stage(buf);
    }
    if (!psp_host_writes_wait_idle(std::chrono::seconds(10))) {
        char buf[96];
        std::snprintf(buf, sizeof buf, "%d host writes still in flight after 10 s; exiting anyway",
                      psp_host_writes_in_flight());
        stage(buf);
    }
    stage("host writes idle");
    psp_audio_out_shutdown();
    ge_draw_shutdown();  // also writes frame.tga for the Patapon 1 scripts
    psp_runtime_shutdown();
    stage("host torn down");
    std::fprintf(stderr, "[RT] Exit 0\n");
    std::fflush(nullptr);
    std::_Exit(0);
}
```
